Additional Accepted Effects (up to 3)

Source note: "Additional" adds another Price*Strength term to the base sum, and the source states up to 3 are possible if all effects are desired by the customer. It does not state what happens with a 4th, so this calculator caps it at 3.

Special Request Multipliers

Ambiguity disclosed, not guessed: the source lists these as independent bonuses but does not state which combinations are possible in a single real transaction (e.g. whether more than one "maximal N types of ingredient" row can apply at once, or whether the "Additional fitting Effects" rows can combine with an "Additional" accepted effect above). This calculator lets you check any combination and multiplies them all together per the published formula; it is on you to know which combination matches your actual in-game request.

Sources & caveats:
  • All base prices, the formula, the strength/special-request/haggling multiplier tables, and the three worked examples used as this page's own tests -- KosGames, "Potion Craft Alchemist Simulator: Potion Price Composition (Version 1.0.5)", published 2023-02-03, fetched 2026-11-18.
  • A second candidate source (gaming.net, "Potion Craft: All Recipes & How to Make Them") was fetched and checked for a cross-check, but it covers ingredient recipes, not the price formula or base-price table, so it contributes no data to this page.
Data is from game version 1.0.5 (February 2023). This single source is the only dedicated price-composition writeup found -- no dedicated Potion Craft price calculator tool exists elsewhere (per Gate 2 search). Prices and multipliers may not match your current game version if the game has been patched since.
The source's three worked examples are reproduced exactly and used as this page's automated tests (see test.js): Mana III + Healing II with both special requests, Trading VII (70%), Popularity 20% = 499; Healing I with four non-satisfying "fitting" effects, Trading IV (40%), Popularity 30% = 91; and a Levitation weak-request example with six stacked multipliers = 17820, haggled at Very Hard = 26730.
Any value not published on the source is not guessed on this page. The source does not state game-mechanics constraints on which special-request checkboxes can be combined in an actual transaction -- that ambiguity is disclosed on the calculator itself rather than resolved by assumption.
